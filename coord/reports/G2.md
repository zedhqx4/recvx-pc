# G2 - Retirar rama PS2 obsoleta de Ps2TexLoad

- Rama: `optimizacion-gpt`
- Archivo modificado: `src/ps2/veronica/prog/ps2_dummy.c`
- Función: `Ps2TexLoad` (línea inicial 3547 antes del cambio)
- Commit de código: `4bbddcca735c0078af62d7a9092d3ce7292ede50`
- Alcance: se eliminó únicamente el `#else` PS2 del `#ifdef TARGET_PC` exterior. El cuerpo `TARGET_PC` quedó sin cambios.

## Cambio realizado

Antes, `Ps2TexLoad` tenía esta estructura:

```c
int Ps2TexLoad(NJS_TEXMEMLIST* addr)
{
#ifdef TARGET_PC
    /* Ruta PC: pcNativeTextureLoad / pcRendererBindTexture. */
#else
    /* Ruta PS2: carga TIM2 y acceso a GS/VU/VRAM. */
#endif
}
```

Se retiró la rama PS2 completa. La rama `TARGET_PC` conserva:
- El caso `addr == NULL`, que limpia `Ps2_now_tex` y `Ps2_now_bank`, y desvincula la textura.
- El caso de render texture que llama a `pcRendererBindRenderTexture()`.
- La llamada final a `pcNativeTextureLoad(addr)`.

La rama retirada tenía 158 líneas de cuerpo y contenía, entre otras cosas, 7 referencias a nombres `pcGs*` en bloques `#ifdef TARGET_PC` internos. Esos bloques estaban dentro del `#else` exterior, por lo que también quedaban excluidos de la compilación PC: no eran la implementación PC activa.

## Verificación

Se extrajo la rama PC de la versión anterior (commit `efc6464514799581e34c7058a2d615831633f367`) y de la versión nueva. La comparación textual de ambas ramas dio:

```text
identical=true
PC_BRANCH_TEXT_IDENTICAL=PASS
```

Se compilaron esos bloques extraídos en un harness mínimo con los tipos y prototipos necesarios, usando C89 estricto. El harness anterior conservó un `#else` de relleno para representar la forma del preprocesador original; el nuevo conservó el `#ifdef TARGET_PC` y su `#endif`, sin rama alternativa.

Comandos ejecutados:

```sh
gcc -dumpfullversion -dumpversion
gcc -std=c89 -Wall -Wextra -Werror -pedantic-errors -fsyntax-only -DTARGET_PC /tmp/ps2_texload_before.c
gcc -std=c89 -Wall -Wextra -Werror -pedantic-errors -fsyntax-only -DTARGET_PC /tmp/ps2_texload_after.c
```

Salida literal:

```text
GCC_VERSION=14.2.0
GCC_PC_BRANCH_BEFORE=PASS
GCC_PC_BRANCH_AFTER=PASS
PC_BRANCH_TEXT_IDENTICAL=PASS
```

El harness está en `/tmp/ps2_texload_before.c` y `/tmp/ps2_texload_after.c` del entorno de trabajo, no en el repositorio. Se verificó la sintaxis del bloque PC aislado; no se compiló la unidad completa, que depende de headers y del SDK del juego.

## Preguntas / límites

- Después de retirar `#else`, la función conserva únicamente el cuerpo bajo `#ifdef TARGET_PC`. Una compilación donde `TARGET_PC` no esté definido dejaría un cuerpo vacío para una función que devuelve `int`. La tarea se definió para la build PC; no se probó ni se pretendió conservar una build PS2 de este archivo.
- No se compiló con MSVC ni se ejecutó el juego. Esas validaciones corresponden al usuario/CI según `coord/README.md`.
